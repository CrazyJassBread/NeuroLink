## Behavior Changes
- Each movement action now moves up to 4 pixels by default, using one-pixel collision sub-steps.
- Direct Gymnasium/human no-op remains valid.
- DreamerV3 training no-op is disabled by default by shifting training action IDs `0..5` to base environment actions `1..6`.
- Optional stuck penalty remains disabled unless explicitly enabled.
