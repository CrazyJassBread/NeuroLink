# 2026-04-30

## Room entry spawn, door unlock rendering, and shield slot

### Summary
- Added directional entry spawn helpers so room transitions place the player just inside the target doorway.
- Added runtime-only locked-door state so unlocked doors render open and do not repeatedly consume keys.
- Added lightweight A/B equipment slots with default `A:interact` and `B:shield`.
- Implemented B shield contact behavior: prevent contact damage, knock monsters back, stun them, and emit structured event details.
- Updated human input so held X repeats B/shield and takes priority over held movement.

### Files Changed
- `env_diy/entities/state.py`: added equipment/tool enums and player equipment state.
- `env_diy/maps/rooms.py`: added entry direction helpers, directional target validation, optional `target_entry`, and exit runtime state.
- `env_diy/envs/dungeon_env.py`: added A/B tool dispatch, directional transition spawn, door unlock state/events, shield block contact handling, and equipment info.
- `env_diy/rendering/renderer.py`: rendered exits using runtime open state and added A/B tools to HUD text.
- `env_diy/rendering/sprites.py`: added an opened locked-door sprite variant.
- `env_diy/input/human.py`: changed held B behavior to repeat shield with priority over movement.
- `tests/test_env_diy_env.py`: added transition, door runtime state, shield, and equipment coverage.
- `tests/test_env_diy_renderer.py`: added locked/opened door render coverage and HUD equipment assertions.
- `tests/test_env_diy_input_state.py`: added held B repeat and priority coverage.
- `tests/test_env_diy_room_loading.py`: added default `target_entry` and blocked directional entry validation coverage.
- `README.md`, `DEVELOPMENT_GUIDE.md`, `env_diy/README.md`: documented entry spawns, door runtime state, shield semantics, A/B equipment, and human input behavior.

### Behavior Changes
- Directional `target_entry` values now spawn the player one tile inside the corresponding target doorway.
- Missing `target_entry` defaults to the opposite of the exit direction.
- Locked-key doors unlock into runtime `opened` state, render as open, and consume keys only on first unlock.
- Action `6` is B/shield. Shield blocks one monster contact tick, applies knockback/stun, and emits `shield_block`.
- HUD now includes equipped A/B tools.
- Observation space and Gymnasium step API remain unchanged.
