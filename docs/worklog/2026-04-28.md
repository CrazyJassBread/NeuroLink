# 2026-04-28

## Summary
- Refactored `env_diy` dynamic movement from tile-step to pixel-step.
- Upgraded `DungeonEnv` observations from a single grid `Box` to a pixel-aware `Dict`.
- Updated collision, monster ticking, transitions, rendering, tests, and docs to match the new semantics.

## Files Changed
- `env_diy/constants.py`: added canonical geometry and speed constants in pixels per environment step.
- `env_diy/entities.py`: introduced pixel-position helpers, AABB collision utilities, and inventory encoding.
- `env_diy/monsters.py`: converted monsters to pixel-level movement with default `0.8x` speed.
- `env_diy/env.py`: rewrote step/reset logic around pixel movement, Dict observations, and per-tick monster updates.
- `env_diy/observation.py`: kept a coarse symbolic grid while sourcing dynamic entity tiles from pixel positions.
- `env_diy/renderer.py`: renders player and monsters at pixel positions.
- `env_diy/game.py`: advances the environment every frame by sending `NOOP` when no input is pressed.
- `README.md`: documented pixel movement, Dict observations, and updated action semantics.
- `DEVELOPMENT_GUIDE.md`: documented pixel movement policy and the preferred `env_diy` observation shape.
- `tests/test_env_diy_env.py`: added pixel-movement, tick, trap/button/exit, and auto-reset coverage.
- `tests/test_env_diy_renderer.py`: added pixel-position rendering checks.

## Behavior Changes
- `NOOP`, `INTERACT`, and `B` now all advance the environment tick.
- Player and monsters move by a few pixels per step instead of jumping one whole tile.
- Room triggers still use tile logic, but derive tile membership from entity center points.
- `DungeonEnv` observations now include both coarse grid and fine-grained pixel state.

## Tests
- Command: `source .venv/bin/activate && python -m pytest -q tests`
- Result: pass

## Known Issues / Next Steps
- Monster pathing is still intentionally simple and does not yet avoid all possible local dead-ends.
- The manual pygame shell uses one action per frame and does not yet support held-key continuous movement.
