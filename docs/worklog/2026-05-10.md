## Single-task dungeon objectives and RL smoke

### Summary
- Added self-contained single-task room configs for `avoid_traps`, `kill_monsters`, and `key_door`.
- Added task metadata parsing, objective finish detection, task reward overrides, and `task_finished` info details.
- Added a dependency-light random-policy single-task smoke script.

### Files Changed
- `env_diy/maps/tasks.py`: task/objective/reward dataclasses and validation.
- `env_diy/maps/rooms.py`: direct self-contained task room loading and task validation.
- `env_diy/envs/dungeon_env.py`: task finish handling, task reward integration, A/interact monster attack fallback, and all-monsters door unlock fix.
- `env_diy/map_data/dungeons/{avoid_traps,kill_monsters,key_door}/room_001.json`: single-task challenge room configs.
- `rl/train_single_task.py`: random-policy single-task smoke runner with finish-rate output.
- `tests/test_env_diy_single_task.py`: map loading, finish condition, reward, and CLI smoke coverage.
- `readme.md`, `env_diy/README.md`, `docs/env_diy_game_guide.md`, `rl/README.md`: updated single-task, objective, reward, info, and smoke instructions.

### Behavior Changes
- `DungeonEnv` can load `env_diy/map_data/dungeons/<task>/room_001.json` directly.
- Single-task rooms expose `task_id`, `task_type`, and `finish` in `info`.
- Finishing an objective emits `task_finished` and `victory`, adds the configured finish reward once, and returns `terminated=True`.
- A/interact still prioritizes chests and NPCs, then attacks adjacent or overlapping monsters if there is no interaction target.
- `all_monsters_defeated` door unlock no longer relies on a missing `RoomState.template` field.

## One-pixel movement, RL action repeat, and cleanup

### Summary
- Changed base player movement speed to `1 px/tick`.
- Kept monster speed at `0.5x` player speed.
- Added RL action repeat wrapper for efficient training with 1px base movement.
- Simplified `env_diy` speed constants and shortened README entrypoints.

### Files Changed
- `env_diy/core/constants.py`: added canonical per-tick speed constants and compatibility aliases.
- `env_diy/entities/state.py`, `env_diy/entities/monsters.py`, `env_diy/envs/dungeon_env.py`: switched defaults to per-tick speed constants.
- `rl/utils/wrappers.py`: added `ActionRepeatWrapper`.
- `rl/utils/env_factory.py`, `rl/train_random.py`, `rl/train_single_task.py`, `rl/train_ppo.py`: added `action_repeat` wiring and CLI flags.
- `tests/test_env_diy_env.py`, `tests/test_rl_action_repeat.py`, `tests/test_rl_smoke.py`, `tests/test_env_diy_single_task.py`, `tests/test_dreamerv3_env_diy_smoke.py`: updated movement and wrapper coverage.
- `readme.md`, `env_diy/README.md`, `rl/README.md`, `docs/env_diy_game_guide.md`, `docs/train.md`: documented 1px base movement and RL action repeat.
- `world_model/dreamerv3/dreamerv3/configs.yaml`, `world_model/dreamerv3/embodied/envs/env_diy.py`: aligned EnvDIY default movement speed with base env.

### Behavior Changes
- Default `DungeonEnv` movement actions now move the player by 1 pixel per environment tick.
- Default monster speed is now `0.5 px/tick`.
- Explicit `move_speed_px` overrides still work.
- `rl/` scripts support `--action-repeat`; rewards are summed across inner ticks and final info includes `action_repeat`, `inner_steps`, and `repeated_reward`.
- `max_steps` in RL scripts remains the outer agent step count; actual env ticks are approximately `max_steps * action_repeat`.
